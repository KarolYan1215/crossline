# 内测受邀者走查（2026-10-15）

以 Tailscale 受邀者的身份，在独立实例上走一遍完整网页版：占位机主先注册（第一个工作区 = 机主 runtime，不登录），人设随后注册，走访客 runtime 与设备码。人设与材料是虚构的（林知夏，Northlake University 机器人方向硕士一年级；课程 RBT 610 / DSC 520 的大纲由本次走查自造，放在会话临时目录，不入库），截图可直接公开。

## 实例

- `scripts/beta-instance.ts`：`build` 构建到 `apps/web/.next-beta`；不带参数同时起 web（3350）与 worker（supervisor 3351）。数据在 `%TEMP%\crossline-beta`，`CROSSLINE_STATE_DIR` 指向其中的 `state\`，机主 runtime 的 Codex home、访客 runtimes、skill-library、浏览器档案都落在那里，不碰 `%LOCALAPPDATA%\Crossline`。密钥首次生成后存 `beta-secrets.json`，重启不掉登录。
- 常驻版的 `apps/web/.env` 与根目录 `.env.local` 里的每个键都在脚本里显式给值（空串即关闭）：Next 与 worker 只补环境里未定义的键，漏一个就会把真实数据目录、Google、SMTP 或 Graph 带进实例。
- `.claude/launch.json` 的 `beta` 配置，打开 `localhost:3350`（不用 127.0.0.1，cookie 不按端口区分）。
- 邮件进 `<data>\mailbox\*.json`。

## 代机主做的决定（机主授权，按「受邀者不看说明也能上手；用户操作尽量少」）

- 登录页如实写明「资料和本人的 ChatGPT 登录都保存在运行这个 Crossline 的电脑上，只能通过私有网络访问；模型用本人的 ChatGPT 额度」。
- 邮箱验证码设为默认登录方式；验证码方式下不显示「注册 / 忘记密码」。
- 首批里程碑草稿由系统自动设计（仍需批准），在访谈结束或停下 20 分钟后才启动，避免挡住访谈。
- 访客看不到也开不了任何读取机主电脑的功能（文件夹、屏幕活动、作息、键鼠、使用记录）和只为机主工作的助手；没有日历写入账号时不提「要创建日程吗」。
- 公开测评结果在访谈开始后才出现的，也照样展示供选择。
- 走查实例的后台任务已暂停，以免继续消耗机主账号额度。

## 走查结果

- 注册 → 连接模型（设备码，需机主在 ChatGPT 安全设置开启设备代码登录）→ 访谈：3 轮达到开始标准（约 20 分钟注意力时间），12 轮访谈完成。
- 主线：15 个草稿，一键批准对话框列出风险与标准，批准后自动倒推出任务。
- 任务：「现在 / 接下来 / 在等 / 任务库」分组清楚；计时、完成（即验收）走通；归档走通。
- 待确认：四象限；修复后只剩真正需要本人决定的事。
- 计划、设置、回来页、离线页：桌面与 375 宽度均无横向滚动、无小于 12px 的文字。
- 测评带入：卡片（代码、名字、组、四轴、形象、海报链接）、「使用该结果」入账并进入访谈上下文、「不是我 / 移除」删除并不再查询，均在实例上走通。
- 全量：`pnpm typecheck` 通过；`pnpm test` 333 个文件、2189 个测试通过。

## 公开测评结果带入 App

契约 `packages/core/src/assess-link.ts`（测评会话负责）。App 端：

- `apps/web/lib/assess-link.ts`：`ASSESS_BASE_URL` 与 `ASSESS_LINK_SECRET` 任一未设置即整段不启用。只用已验证的邮箱向测评服务 `POST /api/link`（Bearer 密钥，5 秒超时）；不可达、非 2xx、返回体不合法都静默跳过，下次进访谈再查。
- `/api/onboarding/assess`：GET 返回 `off | none | offered | used | declined`；POST `{decision}`。只有本人点「使用该结果」才写入 setting `assess.result`（契约字段 + `source: "public-assess"` + `acceptedAt`），写入前重新查询一次，不信页面传回的内容；「不是我的结果」或之后的「移除」删除它并写 `assess.declined`，此后不再查询。
- `/api/onboarding/assess/figure`：形象缩略图由 App 自己的域名转发（`private` 模式的 CSP 只许本域图片），只取测评服务同源的 PNG/JPEG/WebP，≤2 MB。
- 访谈页 `assess-card.tsx`：类型代码、名字、组、测试日期、四轴条、形象、「查看测评海报 →」，两个按钮；访谈开始后才测的也会出现。用过后显示一行「已带入公开测评结果……」与「不是我 / 移除」。
- worker：访谈每轮带 `publicAssessment`（只在已采用时），`crossline-onboarding` 的 SKILL.md 写明只作佐证、画像四轴仍按访谈证据评分、不写出测评的类型名。
- 走查实例：`ASSESS_BASE_URL=http://127.0.0.1:3340`、`ASSESS_LINK_SECRET=beta-walkthrough-assess-link`（`scripts/beta-instance.ts` 默认值）。人设邮箱在测评端做了一次（GEMP 架构师），卡片显示、形象、使用后入账都已在实例上走通。
