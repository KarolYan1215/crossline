按 [commit.html](commit.html)、[wrap.html](wrap.html)、[helper.html](helper.html) 和 [scenarios.md](scenarios.md) 的结论 4、5、6、9、11 实现。周复盘和铃铛没有草稿，按同一套 tokens 和各自的场景重排。截图在 [../redesign-shots-1028/e/](../redesign-shots-1028/e/)：桌面 1440、手机 390，浅色和深色各一份。

## 本周承诺 `/commit`

场景：周日晚、周一，或这周排不下时，定下保、推、砍，确认一次，可撤销。

| 原有功能 | 现在在哪 | 说明 |
|---|---|---|
| 本周可用、需求、保留 | 容量卡上的三个数字 | 「保留后」超过「可用」时变红 |
| 无刻度的进度条 | 容量条 | 竖线标出可用线；超出的部分画红色斜纹，旁边写「超出 N」或「还空 N」 |
| 超出时的警示 | 容量条下方一行 | — |
| 每行的分组（分段控件） | 保、推到下周、不做了三栏 | 每行有两个图标按钮，可改到另外两组 |
| 建议的理由 | 每行「理由：…」 | 本人改过组的，写「本人改到这里；建议…」；里程碑重要性不是默认值时一并标出 |
| 推后的新日期 | 推栏每行写「从 X 起排，截止改到 Y」 | `deferTarget` 不变 |
| 砍的归档说明 | 不做了一栏的栏底 | — |
| 上周回顾 | 容量卡底部一行，链接到周复盘 | 新增 `lastWeekRecap`：上周 `week.committed` 的保留、推、砍，加上上周完成的件数。详情的主场在周复盘（结论 4） |
| 预览影响、确认本周、这周不调整 | 页头三个按钮 | 「确认本周」为主按钮；影响预览显示在页面底部的卡片里 |
| 完成后的撤销、回到今日 | 完成卡 | 不变 |
| 没有任务时 | 说明为什么不用调整，只留「确认本周」 | 原来只有一句话，三个按钮仍然都在 |

拖动把手只是视觉提示（`GripVertical`），拖动本身还没做，见 rituals.md「未做」。

## 收工 `/wrap`

场景：最后一个可用时段结束后，把每个开始过的块记成完成、部分或没做，处理可按推荐的事项，看一眼明天，然后收工。

| 原有功能 | 现在在哪 | 说明 |
|---|---|---|
| 今天开始过的块 | 左卡，每行显示时段、计时、主线标签、任务、步骤 | 新增 `timedMinutes`：该任务的计时落在这个块时段内的分钟数 |
| 完成、部分、没做 | 每行一个三段按钮 | 已回答的块高亮所选的一段，并写明结果 |
| 「全部按预估完成」 | 左卡标题右侧 | 新增。逐个调用同一个 `/api/wrap`，写法与逐个点「完成」相同 |
| 全部按推荐 | 右上卡 | 仍是 `AnswerAll` 组件；主场在待确认，这里是第二个入口 |
| 需要本人回答的去待确认 | 右上卡的说明行 | — |
| 收工 | 页头主按钮 | 还有块没记时写「收工（N 块未确认）」 |
| 今天的数 | 四个数字：今天计时、记为完成的块、待确认的块、明天第一块 | 「计时」按区间重叠计算，暂停按比例扣除；跨午夜的计时只算当天那一段 |
| 明天预览 | 右下卡，明天的前三块 | 读 `loadTimeline`，与今日页的日历是同一份数据 |
| 补记前几天 | `/wrap?day=YYYY-MM-DD` | 新增。只接受最近 7 天（`wrapDayOf`），其余日期一律回到今天。行与写法都与当天相同，键为 `wrap:<那天>:<块>`。补记页不显示「收工」和「明天」，页头只有「回到今日」。今日页「昨天没开始 → 逐个处理」链接到这里 |

## 小帮手 `/helper`（含钉在桌面的画中画窗口）

场景：不在 Crossline 页面时，顺手说一句话、看一眼下一块，或完成一次登录验证。

| 原有功能 | 现在在哪 | 说明 |
|---|---|---|
| 形象与动作状态 | 页头：头像、名字、状态行 | 状态行写当前动作，以及「N 项助手任务在跑」 |
| 需要本人在 app 外完成的事（`HelperCalls`） | 页头的红色药丸，点开是列表 | 只汇总本人在 app 外能做的事（结论 6）。急事仍会在任意页自动弹出 |
| 打开 Crossline / 收起 | 页头图标 | — |
| 日面板（开场卡里的「固定 / 工作」两条时间轴） | 今天的一条时间带，下方一行写「现在 · 下一块」 | 新增 `/api/helper/day`（`helperDay`）。开场卡在窄窗里隐藏它自己的时间轴；「没有要回答的问题」不再显示成按钮的样子 |
| 运行中的助手：进度与停止 | 时间带下方的运行中芯片 | 新增，这里是主场（结论 11）。芯片显示任务名、进度条（按助手自己的计划步数；没有计划时显示「已读 N · 写入 N」）和停止按钮。设置 → 后台任务的完整列表由设置那一路改为摘要 |
| 当天完整对话与搜索 | 中间的对话区 | 主场在这里（结论 9）；各页的输入框只是入口 |
| 输入、附件、@ | 底部输入框 | 不变 |
| 桌宠 `?pet=1` | `helper-desk.tsx`，未改行为 | 气泡、面板、菜单、立绘边框和红点改用 `--ds-*` tokens |

## 周复盘 `/review`

场景：周末或周一早上，回看上周做成了什么、时间投到了哪，然后批准或搁置候选关系、调研结论和洞察提案。

| 原有功能 | 现在在哪 | 说明 |
|---|---|---|
| — | 四个数字：完成的任务、计时、自动验收、待拍板 | 新增。「待拍板」=候选关系+待定的调研提议+候选洞察，点击跳到「要拍板的」 |
| 候选关系的批准与搁置 | 「要拍板的」第一张卡 | 这里是主场，主线抽屉只显示关系并链接过来 |
| 本周调研结论 | 「要拍板的」 | 不变 |
| 信息域扩展（洞察批准与撤销） | 「要拍板的」 | 不变 |
| 本周洞察提案与生成按钮 | 「要拍板的」 | 不变 |
| 本周各线投入（计划与实际） | 「回看」 | 不变；计划页只看未来几周 |
| 本周自动验收与撤销 | 「回看」 | 不变 |
| 累不累 | 「回看」 | 不变 |
| 本月花钱（数字加分类柱状图） | 「回看」里的一行摘要，附链接「看线卡」「看总账」 | 结论 4：记录的主场在主线线卡的领域记录。分类柱状图已去掉 |
| 里程碑达成标准、停转提示、待判断的问题 | 「回看」 | 不变 |
| 已验收作业计数 | 页脚 | 不变 |
| 侧栏入口 | 「节奏与回顾 → 周复盘」 | 原来只能从主线页进入 |

## 提醒铃铛（弹层）

场景：回到电脑前，看系统刚才做了什么、发过哪些提醒，然后点进相关页面。铃铛不做决定。

| 原有功能 | 现在在哪 | 说明 |
|---|---|---|
| 未读红点与计数 | 不变 | 颜色改用 `--ds-alarm-ink` |
| 新提醒弹出 8 秒 | 不变 | 改为卡片样式，左侧红条 |
| 消息列表 | 分「今天」「更早」两组 | 新增 `noticeGroups`；未读的条目左侧有红条 |
| 消息的链接 | 药丸链接 | 只跳转 |
| 带操作按钮的消息 | 「在小帮手里处理 →」 | 跳到小帮手，在铃铛里不作答（结论 6） |
| — | 弹层顶部一行说明，底部「去待确认 →」 | 新增。说明要拍板的事在待确认 |
