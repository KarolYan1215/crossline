## 待确认：三栏

- **页头**：「本周 N 项 · 预计 X 分钟 · 以后再定 M 项」。其中 N 是实时计数；X 由 `approvals/estimate.ts` 计算：已有 5 次计时的作答后，每项待决按本人作答用时的中位数算，否则按 45 秒；提议、验收、助手成果各按自己的时长。右边是「全部按推荐 · N 项」，旁边先列出各种类和「一次撤销」。
- **左栏**
  - 四格计数，点一格筛选中栏。
  - 种类：风险与逾期、等待到期、步骤与准备、助手、验收、日程与承诺、收集与文件、其他。点一类筛选中栏。
  - 快捷键说明。
  - 「以后再定」：四周分布条，点开页底折叠。
  - 「不在这里处理」：访谈题数、里程碑草稿、分数线、文件日期、调研建议、候选关系，各给一个链接。
- **中栏**：一次一张卡。
  - 数字键选项（选项右侧标出键位）；有补充字段的选项直接展开字段，普通选项等 Enter。
  - Enter 确定，J / K 翻页，H 明天再问。快捷键只在没有输入焦点、没有对话框时生效。
  - 鼠标点选项仍是一键作答。
  - `?ask=<id>` 把那张卡翻到最前（今日页的「打开」）。
- **右栏**
  - 助手成果：每项一行，点开是完整成果与审阅按钮，正文在展开时才读取。
  - 待验收，任务提议（批量批准），权限模式面板（开启时），最近自动生效（24 小时内撤销）。
- **手机**：一栏，顺序为四格、卡、右栏各卡、以后再定、不在这里处理、种类。键位提示隐藏。
- **访谈问题（结论 8）**
  - `listed` 不再列出 `interview_question` / `interview_open`：待确认、今日、徽标、通知快照都不再出现。
  - 这两类问题仍在 `collectAsks` 里，所以从输入框作答仍然有效。
  - `PendingCounts.questions` 现在是访谈未完成时的题数，不计入 `total`，只用于左栏那一行。
