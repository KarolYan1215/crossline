## 完成组件 API（`apps/web/app/task/task-completion.tsx`）

```ts
TaskCompletion({ task, stepId?, onDone? })
TaskCompletionSheet({ task, stepId?, open, onOpenChange })   // Sheet，标题「完成并提交材料」
COMPLETABLE                                                   // ["approved", "ready_for_human", "active"]
```

- `task`：`TaskDetail`（卡片的 `cardView` 副本也可以；Sheet 打开时会读完整详情，补上清单与屏幕记录的分钟数）。
- `stepId`：从某一块打开时传入这块的步骤；还有其他未完成步骤时多出「只完成本步」。
- 未开始计时的任务会先开始再完成；离线时没有文件的完成会排进离线队列。
- 今日页块面板的「完成并提交材料」改为：

```tsx
{completing && <TaskCompletionSheet task={detail} stepId={step?.id} open={completing} onOpenChange={setCompleting} />}
```

之后 `timeline/complete-dialog.tsx` 可删去（它与本组件的提交路径相同，表单是本组件的子集）。
