# Crossline 节点安装教程

「Crossline 节点」装在本人自己的 Windows 电脑上。电脑开着时，网页版的模型工作、读取本人登录的网站、剪辑视频等工作改在这台电脑上做，花的是这台电脑上登录的 ChatGPT 账号或 API key 的额度。电脑关机或暂停时，工作回到服务器，网页版照常可用。

适用于 Windows 10（1809 及以后）和 Windows 11，64 位。安装不需要管理员权限。

## 1. 下载

在浏览器里打开下面的地址，下载安装包：

https://github.com/KarolYan1215/crossline-releases/releases/latest/download/Crossline-Node-Setup.exe

如果浏览器提示「通常不会下载此文件」，在下载列表里点该文件旁的「…」，选「保留」，再选「仍然保留」。

## 2. 运行安装包

双击 `Crossline-Node-Setup.exe`。安装包没有商业代码签名证书，Windows 会弹出蓝色的「Windows 已保护你的电脑」（SmartScreen）：

1. 点窗口里的「更多信息」。
2. 发布者一栏显示「未知发布者」，属正常情况。点「仍要运行」。

安装向导里有两个选项：

- 「登录 Windows 时自动运行」：默认勾选。勾选后，电脑开机登录即开始提供算力。不勾选也可以，之后在托盘菜单「开机时启动」里随时更改。
- 「在桌面创建快捷方式」：默认不勾选。

程序装到 `%LOCALAPPDATA%\Crossline Node\app`。安装结束时勾选「现在启动 Crossline 节点」，点「完成」。

## 3. 配对

节点启动后，屏幕右下角的通知区出现 Crossline 图标，并自动打开节点设置页（浏览器里的 `http://127.0.0.1:47391/`，只在这台电脑上能打开）。页面上显示一个配对码，形如 `ABCD-EFGH`。

1. 在另一个浏览器标签页打开 https://app.crossline.lol 并登录网页版账号。
2. 进入「设置 → 通用」，找到「这台电脑」卡片。
3. 在「独立节点」一栏填入配对码，点「配对」。

配对码 10 分钟内有效，过期后节点设置页会自动换一个新的。配对成功后，节点设置页显示「已配对」。

## 4. 登录模型

节点用这台电脑自己的模型登录，二选一：

- **ChatGPT 账号**：在节点设置页点「登录 ChatGPT」，浏览器打开 OpenAI 的登录页，登录后回到节点设置页即可。之后的用量计入该 ChatGPT 账号的额度。
- **OpenAI API key**：在节点设置页的 API key 一栏粘贴以 `sk-` 开头的 key，点「用 API key 登录」。用量按该 key 计费。key 只保存在这台电脑上节点自己的 Codex 目录里，不会发送到网页版，也不写进日志。key 填错时，第一次运行模型才会报错。

登录完成后，节点设置页的「运行状态」显示「已接入」。

## 5. 允许在这台电脑上执行命令（可选，默认关闭）

节点设置页有一个开关「允许在这台电脑上执行命令」，默认关闭。

关闭时，节点只替网页版运行模型和读取网站，不在这台电脑上执行任何命令。

打开后，助手可以在这台电脑上执行命令，用于：

- 剪辑音视频和图片（安装包已附带 FFmpeg，不需要另外安装）；
- 按本人的要求生成新的工作流；
- 准备需要对外办理的事，例如填好表格、写好邮件、整理好报名材料。这类事助手只做到最后一步之前：发送、报名、付款、提交这一下始终由本人自己点，助手不会代为完成。

助手执行的每条命令都有记录，可在网页版助手结果的详情里查看。涉及密码与密钥文件、对外发送和系统设置的命令会被拒绝。不需要时随时关掉开关即可。

## 6. 哪些东西留在这台电脑上

- 配对令牌：用 Windows 自带的数据保护加密保存，只有当前 Windows 用户能读取。
- ChatGPT 登录或 API key：保存在 `%LOCALAPPDATA%\Crossline Node\codex-home`。
- 读取网站时用的浏览器资料（包括本人在其中的网站登录）：保存在节点自己的目录里，与本人日常使用的浏览器资料分开。
- 日志：`%LOCALAPPDATA%\Crossline Node\logs`。
- 助手执行命令时处理的文件：在这台电脑上的任务目录里，完成后的产出交回网页版。

网页版收到的是每次模型运行的结果和读取到的内容，不会收到 ChatGPT 密码、API key 或配对令牌。

## 7. 日常使用

托盘图标的菜单里有：显示小帮手（快捷键 Ctrl+Alt+H）、打开 Crossline 网页、节点状态、暂停算力 / 继续提供算力、节点设置与登录、检查更新、开机时启动、退出。

暂停算力后，工作回到服务器；配对和登录都保留。有新版本时，托盘会提示，确认后自动下载并安装。

## 8. 卸载

1. 打开 Windows「设置 → 应用 → 已安装的应用」。
2. 找到「Crossline 节点」，点「…」，选「卸载」。
3. 卸载时会问「是否同时删除这台电脑上的配对和 ChatGPT 登录」：
   - 选「是」：删除配对令牌、ChatGPT 登录、API key 和日志。
   - 选「否」：保留它们，重新安装后不用再配对和登录。

网页版账号里的数据不受卸载影响。如需同时解除配对，在网页版「设置 → 通用 → 这台电脑」卡片里解除。
