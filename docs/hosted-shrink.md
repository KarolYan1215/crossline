# 托管版收缩：访谈 + 报告 + 自用（草案，2026-11-04）

状态：草案，等本人逐条拍板。拍板后按 §8 拆成会话执行。

**2026-11-04 已定**（总览见 `docs/editions.md`）：

- 部署用 §3 的 A 方案：同一镜像、两套栈，数据分开。report 栈占内存小。内存不够时，本人主账本搬回本机。
- 收费：私域收款 + 小红书商城 + 兑换码。
- 买家可以导出带走；访谈原文 90 天后删除。
- 报告只能通过网页访谈生成。
- 其他人付费后，也可以在网页版使用全部功能。这一条改写了 §1 的“不再做”清单，见 `editions.md` §3。

## 1. 目标与边界

托管机（香港 3.5 GB / 2 CPU）以后只做三件事：

1. **公开快测**（`apps/assess`）：不变，是免费入口。
2. **付费深度访谈报告**：陌生人在网页上做完访谈，拿到画像报告（类型、形象、长图、私密下半份）。卖的是结果，不卖模型额度。
3. **本人自用**：本人的主账本（device mode 已定：托管站是唯一主账本）。全部功能照旧。

不再做：给他人用的规划、日历、邮件、助手、自动化；访客各自的 Codex 运行时；邀请码换开发者模型；免费注册。

## 2. 现状里要拆掉或改用的东西

| 现有 | 处理 |
|---|---|
| 访客 Codex 运行时（`runtime-registry.ts`，每人一个 CODEX_HOME 和进程） | 报告栈不需要：报告全走开发者模型（provider 线程不带账户）。待核实：provider 路由今天是否仍为每个工作区起一个访客运行时；若是，报告栈改为共用一个运行时 |
| 邀请码（`beta_invites`、`/invite/decide`） | 改作**报告兑换码**：私域收款后本人通过申请，码发到买家邮箱，兑一份报告 |
| 开发者模型（`sponsor.ts`） | 保留，改成报告的唯一模型，加上本人 ChatGPT 额度用尽时的替补 |
| 访客的 ChatGPT 登录、设备码、API key 连接（`/connect`） | 报告栈不提供 |
| 免费注册 | 关闭。自用栈只认本人邮箱（`CROSSLINE_SIGNUP_ALLOWLIST`，机制已有）；报告栈只认持码人 |
| 现有测试者账户 | 先通知、给导出（`pnpm export` 或迁移到本机安装版，`migrate-workspace.ts`），到期删除（`purgeWorkspace` 已有） |
| 模型门的多租户公平（`model-gate.ts`） | 不动。单租户下无害，报告栈多个买家时仍有用 |

原则：**先用配置关掉，再分批删代码。**开源版要不要带这些代码，跟开源计划一起定。

## 3. 部署形态（三选一，推荐 A）

**A. 同一镜像、两套栈、两份数据（推荐）**

- `crossline-owner`：web + worker + transcriber，数据目录 `/data/owner`，只有本人。
- `crossline-report`：web + worker，数据目录 `/data/report`，自己的 `auth.db`，`CROSSLINE_EDITION=report`。
- `assess` 不变。
- 优点：代码不分叉；陌生人的数据和本人账本是不同文件，备份、删除、泄露面都分开。
- 代价：内存。粗估 owner worker 1000m + web 450m，report worker 800m + web 350m，assess 450m，transcriber 750m 只在夜里跑，合计约 3.0–3.8 GB，超出 3.5 GB。需要实测，可能要 transcriber 和报告栈错峰，或升到 4 GB 机器。

**B. 一套栈，加“报告账户”类型**

- 现有栈里，持码账户只能进访谈和画像页，worker 只给它跑访谈相关的 pass。
- 优点：最省内存，改动最少。
- 代价：陌生人数据和本人账本在同一个 `crossline.db`（靠 workspace 隔离，`isolation.test.ts` 有证据），备份文件里也混在一起。

**C. 新写 `apps/report`，像 assess 一样独立**

- 隔离最干净。
- 代价：访谈 runner（`onboarding-session.ts` 547 行、`onboarding-extract.ts` 395 行）和画像 writer 都绑着 `CrosslineStore`，要抽一层存储接口，工作量最大。

## 4. 报告产品定义

做法：一次访谈的会话加画像生成，跑在报告栈上，模型用开发者模型（DeepSeek V4.1-Flash 等，`sponsor.json` 的选择）。

报告内容（现有画像报告去掉“需要长期使用数据”的部分）：

- 上半份（可分享）：思维模式类型、形象、类型说明、四维、标签、分享卡和长图。
- 下半份（私密）：真问题、指南针、能量、各条线、建议矩阵。
- 去掉或降级：
  - 言行对照：需要 14 天、10 次执行，报告栈没有。只留“所说”。
  - 精力节律：需要睡眠记录。用默认作息画，标注“未记录作息，按常见作息估计”；或者干脆不放。**待定**。
- 形象：每份报告最多 3 张（`CROSSLINE_IMAGE_PER_ACCOUNT` 已有），用 Ark key。

交付之后的桥：报告页给“带走我的访谈”按钮，导出访谈事实、画像和线，供导入本机开源版继续使用。这是开源版的拉新入口。

## 5. 收费与合规

- **收费**：先走私域（微信收款）+ 兑换码，不接在线支付。在线支付牵涉经营许可和支付牌照，等量起来再说。
- **单份成本**：未测。第一步用开发者模型跑完整流程测量（访谈约 12 轮，加抽取、画像 writer、illustrator），再定价。
- **合规清单**（服务大陆用户时）：
  - 生成式 AI 服务登记，并展示所用模型的备案号。
  - AI 生成内容标识：报告和图片都标“AI 生成”。
  - PIPL：访谈内容含敏感个人信息（健康、财务、宗教等可能出现），要单独同意；隐私页（`/privacy`）补报告条款。
  - 数据留存：默认出报告后 N 天删除访谈原文（assess 是 90 天，`purge.ts`），买家可提前删除。
  - 不在大陆转售 OpenAI 服务：报告栈不用 ChatGPT，只用开发者模型。

服务器在香港不需要 ICP 备案，但面向大陆用户提供生成式 AI 服务的登记要求仍可能适用，需要再确认。

## 6. 自用栈

- 环境基本照旧：本人 ChatGPT 运行时、开发者模型替补、device mode、算力节点。
- `CROSSLINE_PUBLIC_BETA` 现在同时代表“托管机上没有‘这台电脑’”和“多人公测”，要拆成两个含义：
  - `CROSSLINE_HOSTED=1`：没有本机文件夹、屏幕等。
  - `CROSSLINE_EDITION=owner|report`。
  
  `isHostedBeta()` 的十几个调用点逐个归类。
- 并发和内存设置按单用户下调（模型并发、访客运行时数都可以降），省下的内存留给报告栈。

## 7. 风险

1. 内存：两套栈可能放不下，要实测（§3 A）。
2. 访谈质量：报告全走开发者模型。V4.1-Flash 的样本访谈读起来过关，但完整访谈加画像从未在它上面端到端跑过。
3. 合规：登记周期和要求不明确，可能卡上线。
4. 测试者迁移：现有测试账户怎么通知、给多久、带走什么，要有个公告。
5. 开源冲突：报告的 prompt、类型表、32 张模板、海报渲染如果留在开源仓库，就卖不了结果。开源前要把这些移到私有包或服务端。
