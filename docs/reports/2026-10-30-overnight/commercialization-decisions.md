## 2. 替代风险：哪一层守得住

D1 的第一个判据，按功能层逐层检验：

| 层 | 大厂有没有动机 | 判断 |
|---|---|---|
| 反推规划、拆步骤、写教程 | 有（Muse 已宣传「一年期计划」） | 6–12 个月内被替代 |
| 日历自动排程 | 有（Google、微软的日历是原生的） | 被替代 |
| 记忆、简报、定时任务 | 有 | 已被替代 |
| 逐块确认、计时、证据验收，诚实地说「没做」 | 弱：大厂优化留存和好感 | 有需求就能被复制，但动机弱，能撑 1–2 年 |
| 从执行事实读出的复盘 insight（计划与实际的差、每条线的兑现率） | 弱 | 同上，而且依赖账本里的历史，越用越难换走 |
| 研究或课程的垂直流程（大纲→成绩线，论文→投稿节点） | 低：市场太小 | 能撑，但天花板低 |
| 跨多个 agent 的中立账本 | 反向：大厂要锁定用户 | 长期有价值，现在市场小 |

**对 D6 的说明。** 定位里的三项耐久度不同：

- 「多主线规划」和「自动化执行」是最先被大厂覆盖的层。
- 「可复盘的数据 insight」最耐久。

对外文案保留三项，但 **insight 放第一位**，规划和自动化写成获取数据的手段。不然用户会拿它和 Muse 比，比的正好是 Muse 最强的那一项。

## 3. 模型来源与合规

### 3.1 三条模型通道

1. **开源本机版。** 用户自己的 Codex 登录（现状），或用户自带 key。
   - 本人判断，免费、开源、跑在用户自己电脑上，与 Codex 的本来用法一致，风险低。
   - **边界：本机版本身要一直免费。** 本机版只要收费（例如「专业版解锁」），就又落回 app-server 条款里「commercial」那一条。
2. **SIWC 计划额度（备用通道，不急）。** OpenAI 开发者文档：「ChatGPT plan usage is available to all open-source partners and selected private clients」；开源客户端的登录「issues OAuth credentials for eligible Responses API requests, without a client secret or partner API key」（[SIWC Quickstart](https://developers.openai.com/siwc/quickstart)）。
   - 回调只接受 `127.0.0.1`，所以只适用于本机版（[Pydantic AI](https://pydantic.dev/docs/ai/models/openai-chatgpt/)、[TanStack](https://tanstack.com/ai/latest/docs/adapters/openai-advanced)，二手）。
   - 收费或托管的应用要先经 OpenAI 批准（同上二手来源，未核实原文）。
   - 「open-source partner」的门槛没核实。
3. **托管版。** 国产模型（开发者付费），或用户自带 key。

### 3.2 本人承担的已知风险

- **D10。** 从现在到开始收费（第 4–6 月），托管内测继续在服务器上跑访客的 Codex 登录。这期间开源发布在第 2–3 月，也就是说，开源发布后这条路仍然开着。条款原文（`beta-launch.md` §10.3）：「App-server authentication has never been permitted for commercial or hosted services」。被认定违规时，受影响的是用户的 ChatGPT 账号。
- **大陆版（D14）。** 面向境内公众的生成式 AI 服务，调用已备案模型的由地方网信办登记，并须公示模型名称和备案号（[新京报](https://m.bjnews.com.cn/detail/1789387872129240.html)）。个人能不能作为登记和收款主体，没查到官方说法。

## 4. 定价与毛利约束（D9）

| | 海外 $16.9 | 大陆 ¥49.9 |
|---|---|---|
| 每活跃用户月模型成本上限（售价的 30%） | 约 $5 ≈ ¥36 | ¥15 |
| 按 V4-Flash 约 $0.14 / $0.28 每百万 token（[morphllm](https://www.morphllm.com/deepseek-api)，聚合站，未核实官网）大约能撑 | 每月 2000–2500 万 token | 每月 800–1000 万 token |
| 收款手续费 | Paddle 约 5% + $0.5（二手） | 支付宝或微信约 0.6%，需要收款主体 |
| 模型 | 国产模型；质量不够时用 OpenAI API | 只能用国产模型 |

约束：

- **月 token 上限是毛利的保险丝。** 超出后降到更便宜的模型，或提示改用自带 key。
- **现在的用量撑不住大陆档。** 10 月真实账号的重度用量约每月 3000 万 token。上线前要用托管站 11 月的 `model_usage` 实测，看 token-economy 那批改动降到了多少。
- **价差。** ¥49.9 约是海外价的四成。人民币档要绑定大陆手机号或大陆支付，防止海外用户用支付宝套利。
- **竞品参照**（聚合站，数字互有出入）：
  - Motion 约 $19（年付）（[costbench](https://costbench.com/compare/motion-vs-reclaim-ai)）
  - Sunsama 约 $17–22（[techpresso](https://academy.techpresso.co/reviews/is-sunsama-worth-it)）
  - Reclaim 有免费档，付费约 $10–12
  - Focusmate 约 $8–12（[toolradar](https://toolradar.com/tools/focusmate/pricing)）
  - Tiimo 约 $7–8（[lifestack](https://lifestack.ai/blog/tiimo-pricing)）
- **托管版收的钱买的是便利**：不用安装、手机和 Mac 能用、多设备同步、模型包含在内。功能本身在开源本机版里都有。

## 5. 指标与停止条件（D12）

| 层 | 指标 | 线 |
|---|---|---|
| 北极星 | 每活跃用户每周确认完成的步数 | ≥3 |
| 激活 | 注册后 48 小时内完成访谈并确认第一个块 | ≥50% |
| 计划兑现 | 实际做的分钟 ÷ 早上排的分钟 | ≥0.6（模拟里是 0.17–0.39） |
| 留存 | W4 | ≥35% |
| 付费 | 付费人数 ÷ 活跃人数 | ≥5% |
| 付费留存 | M3 | ≥60% |
| 成本 | 每活跃用户月模型成本 | ≤ 售价的 30% |
| 替代信号 | ChatGPT、Muse 或 Gemini 上线「目标→里程碑→日历块→完成追踪」的结构化视图 | 出现就复盘 D6 |

**停止条件：**

- **第 2 月末。** 每周完成 3 步以上的内测者不到 30%：不进入收费阶段，回头查「为什么输出到不了人」。可能是排程过满、决定太多，或人群不对。
- **第 6 月末。** 付费不到 50 人：停止托管运营，只维护开源版，当作品集。

## 6. 6–12 个月计划（D15，已按 D14 调整）

每周时间分配（D16）：开发 15 小时，用户访谈与观察 6 小时，内容 4 小时，运维 2 小时。前两个月开发只修执行闭环。

| 月 | 目标 | 动作 | 过线才进下一步 |
|---|---|---|---|
| 1–2 | 证明闭环 | 冻结新功能，修执行闭环（主会话在做）；本人连续自用 14 天；招 10–20 名本校同学和独立开发者内测，两组用不同的报价问付费意愿；小红书每周 1–2 篇 | 每周完成 3 步以上的 ≥50%（不到 30% 就停）；计划兑现 ≥0.6 |
| 2–3 | 开源 + 分发 | 整仓开源发布（GitHub、Show HN、V2EX）；MCP 只读接口加 capture（D7，与独立产品并行）；速测结果页导流 | GitHub star、本机安装数、MCP 周调用人数 |
| 3 | 收费前准备 | 用 11 月 `model_usage` 实测成本，设好每档的月 token 上限；申请 Paddle 或 Lemon Squeezy；**办大陆的收款主体并提交地方登记**（D14 的前提）；定收款主体（D13 在这里必须有答案） | 每活跃用户月成本 ≤ 售价的 30%；收款渠道获批；登记已提交 |
| 4–6 | 收费验证 | 海外 $16.9 和大陆 ¥49.9 同时上线，创始会员年付优惠；**服务器上不再跑访客的 Codex 登录**（D10）；看 W4 留存 | 第 6 月末付费 ≥50 人，否则停托管 |
| 6–9 | 选人群 | 比较研究生和独立开发者两组的付费率与留存，只留一组深做 | M3 付费留存 ≥60% |
| 9–12 | 形态决定 | 按 MCP 调用占比、App 打开率和付费留存，决定以独立 App 为主还是 MCP 执行层为主 | — |

**依赖。** D14 要求第 4 月大陆版和海外版一起上，那么第 3 月必须办好收款主体并提交登记。登记周期没查到，如果第 4 月还没批下来，大陆版顺延，海外版照常上。

## 7. 未决事项与本人承担的风险

- **D13 身份与收款（未决）。** 如果本人在美国持 F-1 身份，二手资料普遍认为：在读期间自己经营、收入的生意一般不被允许；OPT 期间可以自雇但须与专业相关；STEM OPT 不允许自雇；只持股、准备和规划不算经营（[Babson ISSS](https://babson.edu/glavin-office/isss/employment/entrepreneurial-activities/)、[Klasko Law](https://www.klaskolaw.com/murky-f-1-employment-questions/)、[Berardi](https://berardiimmigrationlaw.com/f1-students-start-business-opt-stem/)，律所与学校页面，非 USCIS 原文）。这一条关系的是身份，比 OpenAI 条款的后果更重。**第 3 月的收费前准备里，它是必须先有答案的一项。**
- **Paddle 对新个人卖家常拒绝。** 一个案例说要求约 3 个月交易记录（[dev.to](https://dev.to/pavelbuild/paddle-rejected-my-saas-3-times-heres-what-they-check-that-isnt-in-their-docs-5dnn)，单个案例）。所以第 3 月就要申请，并准备 Lemon Squeezy 作备选。
- **D10 的条款风险**，见 §3.2。
- **D5 纯软件订阅，正面迎着免费的大厂和 Reclaim 的免费档。** 讨论里的推荐是每周人工复盘：人工问责已经有人花 $100–500/月 买（[Paperbell 例](https://app.paperbell.com/checkout/packages/211676)、[Global Research Coaching](https://selar.com/n277135d77)，个体报价页）。本人没有采用。第 6 月付费数不到线时，这是首先要回头试的方案。
- **D11 四条渠道同时做，每周 4 小时的内容时间偏紧。** 讨论里认为速测用户和目标人群重合度低，建议它只做辅助入口，不单独投时间。
