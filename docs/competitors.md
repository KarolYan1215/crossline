## 科研工具

研究者实际用的是一组工具，而不是一个平台：Zotero（7 版有本机只读 HTTP API）、Elicit、ResearchRabbit、NotebookLM、Overleaf、Quarto、DVC。ELN 多为机构强制采用，而非研究者自选。

借鉴方向是集成而不是重做：Zotero 本机 API 可作为证据和材料来源，Git、DVC、Quarto 的产物可作为「图由某次提交重新生成」的证据。**均未做。**

## 证据依据（设计按这些做，不按直觉做）

| 机制 | 效果 | 来源 |
|---|---|---|
| 具体的目标 | d≈0.34；公开或有难度时更强 | Epton 等 2017 元分析 |
| 进展监测 | d≈0.40；记录下来、报告出来时更强 | Harkin 等 2016 元分析（138 项研究） |
| 实施意图（何时何地做） | d≈0.65；现场实验里写下「日期+时间」才显著，+4.2 个百分点 | Gollwitzer 与 Sheeran 2006；Milkman 等 2011（PNAS） |
| 做计划本身 | 消除未完成目标带来的侵入性思维 | Masicampo 与 Baumeister 2011 |
| 外部提醒 | 提高意图被执行的比例 | Risko 与 Gilbert 2016 |
| 受保护的专注时段 | 随机对照：专注时间 +8–11% | Microsoft Research CAP 研究 |
| 拆开再估时 | 降低规划谬误 | Kruger 与 Evans 2004 |
| 反馈真实的历史用时 | 降低低估 | Roy、Christenfeld 与 McKenzie 2005 |
