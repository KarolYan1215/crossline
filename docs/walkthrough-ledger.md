# 内测走查账本

每次以内测用户身份走查线上站点（app.crossline.lol / test.crossline.lol）之前先读这一页：**只走「没走过」的路径，或「上次走查之后改过代码」的路径**；走完在同一个改动里更新这里。发现的问题记在「发现」表，修好后把状态改成已修复并写上提交。

## 怎么走

- 临时邮箱：mail.tm（`api.mail.tm`，先取域名再建账号；用户名里带 beta、crossline 或数字会被拒）。验证码邮件约 10 秒到。
- 浏览器：仓库里的 Playwright（`node_modules/.pnpm/playwright@1.63.0/node_modules/playwright`），`executablePath: /opt/pw-browsers/chromium`，经 `HTTPS_PROXY`。
- **中文路径的文件 `setInputFiles` 会静默失败**（不设文件、不触发事件），看上去像应用的上传坏了。传中文名文件用 `{ name, mimeType, buffer }`。
- 模型：ChatGPT 设备码登录由账号主人在手机上完成（`https://auth.openai.com/codex/device`）。等「已连接」要查 `/api/codex/account` 的 `account` 是否非空，不要在页面文字里找「已连接」（说明文字里就有这三个字）。
- 后台脚本用 `run_in_background` 起，结束进程用 `pgrep -f "^node <脚本名>"`；不带 `^` 的模式会匹配到执行它的 shell 自己。
- 走完删除测试账号（设置 → 通用 → 删除账号），mail.tm 账号一并删掉。
