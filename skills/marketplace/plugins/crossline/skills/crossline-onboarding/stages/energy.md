# 本阶段：energy 能量

什么让人投入、什么耗人，以及本人怎么做事。这一阶段看 D1、D7 和做事方法。

右栏：画像图；点开 D1 是「擅长 × 热爱」的能量平面，下面是量表读数（偏高、中等、偏低，从不显示分数）。谈到量表时只说倾向在本人日子里怎么表现，不报数字。

1. **完全投入的时刻：具体是什么、和谁。** 投入时在做什么、身边有谁，比「喜欢什么」更能说明能量从哪来。
2. **累但满足的，和做得好也耗人的。** 两类都问：做得好却耗人的事，排日程时要留恢复的时间。
3. **一天的节律。** 哪段最清醒、哪段最累，通常几点睡几点起：日历直接用它排深度工作。
4. **一个早就不管用了还放不下的想法或计划。** 它常常占着本人的时间和注意力，自己却没算进去。
5. **近一年最生气、最羞愧、最嫉妒、最骄傲的一件事（D7）。** 嫉妒尤其有用：它指向本人想要却没说出口的东西。最骄傲的事常常就是经历部分讲过的高峰：题干里排除它（「那次考试之外，近一年还有哪件让你骄傲？」）。
6. **做事方法，两三个问题，按本人自己的主线和项目措辞。** 考核或截止快到时怎么准备、怎么学新东西和复习、怎么写或讲（先列提纲还是先写稿，一个人还是和人一起）。问上一次实际怎么做的，给具体而多样的选项加「没有固定方法」；不把学校或培训的套路（订正、错题本、背诵、打卡）当默认答案，也不从角色推断：方法因人而异，猜错了本人只能再纠正一次。
7. **问一次本人想让应用怎么配合。** 一张 `multi` 卡，具体选项加「都按默认」：几点后不提醒、早上摘要什么时候发、一段专注最长多久、一天排多满、截止前留多少缓冲、助手可以替本人做什么（查资料整理、起草文字、起草邮件回复）。
