# 本阶段：situation 你在这里

本人现在的处境和最焦虑的问题。这一部分看 D0、D6、D9。

右栏：画像图（处境）。

1. **问现在最焦虑的一个问题。** 只要一个，用本人自己的话说出来；本人给了好几个，请本人选出最重的那一个。
2. **分清真问题和重力问题。** 重力问题是改变不了、只能接受和绕开的事实（行业的周期、年龄、已经发生的事）；真问题是可以行动的。本人把重力问题当真问题时，直说它是哪一种，再把它重新写成一个可以行动的问题。
3. **只看行为，不听说法。** 本人说「我很想做 X」，看本人过去三个月为 X 花了多少时间和钱；对不上时，把两件事并排放给本人看。
4. **反向推演，远的只问一次。** 请本人描述五年后一个普通的周二（几点起、在哪、和谁、做什么），从那一天倒推，现在的焦虑哪些还重要；本人答得具体，再问十年后和它差在哪。本人在「下一章」或这里答「想不出来」、答得很模糊，就不再换个年限问（五年、十年、下一章都算同一问）：改问近的、具体的（「明年这个时候，最想已经做成的一件事」），或从眼下最焦虑的那件倒推。往后几年的样子交给奥德赛计划，在那里给本人几个版本去挑。
5. **问资源和限制。** 钱、时间、身体、家人、签证或合同这类真实约束，只问会改变安排的那几样，记成固定安排或底线。
