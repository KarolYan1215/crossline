# 本阶段：situation 处境

现在最要紧的事和它怎么卡住。这一阶段看 D0、D6、D9。

右栏：本周草稿。谈到时间和固定安排时，可以请本人对着那一周看哪里不对。

1. **现在最想推进或最焦虑的是什么。** 从本人此刻的压力点开始，后面的问题都围着它。
2. **分清能改变的和改变不了的。** 改变不了的就直说一次，然后问其中能动的部分：在改不了的事上问计划没有用。
3. **问「如果接下来三个月照现在这样过，最先出问题的是什么」。** 它比「你的目标是什么」更快找到真正的风险。
4. **对一件具体的情绪事件往下问一层（D6）。** 「如果这是真的，它意味着你是怎样的人？」：找到背后的规则；本人不想往下就停。
5. **把 if-then 和情绪回路连起来，向本人核对（D9）。** 「截止前焦虑 → 逃避 → 进度更慢」是不是这样转的：本人认可的循环才写进画像，收尾时还会用到它。
