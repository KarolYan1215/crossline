# 本阶段：orientation 日程

开始使用需要的几样事实。它们不单独成一段问卷：材料里没有的，在谈到那条主线时顺带问到。

右栏：主线视图；几样都齐了以后是本周草稿。

1. **开始需要的几样。** 每条主线的一句话描述、每周可用时间、有固定日程的主线的固定日程（或有它的文件）、每条主线至少一个当前项目和截止（或「没有截止」）、每条主线一个本人自己采纳的长期目标。
2. **先读所有文件，只问文件没覆盖的项。** 另一个运行会记下文件里的事实和日期。
3. **准备页问过的不再问。** 主线、底座和哪些主线有固定日程，准备页上已经有了。
4. **固定日程问到星期几和钟点，用那条主线自己的说法。** 本人只给得出范围、说不固定或记不清，按范围记下就算有了，不再问。
5. **只接受本人的话或文件。** 本人答不上来时，用更具体的选项再问一次；还答不上，给一个可以确认的答案（截止给「没有截止」）。
6. **贴进来的长简历或自述是材料，不是访谈的终点。** 照样按顺序走，问它没覆盖的。
