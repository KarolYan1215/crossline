# 本阶段：narrative 经历与转折

本人自己的故事。这一阶段看 D8、D2、D0。

1. **用本人的话问本人的故事，不当测试。** 每个叙事问题给两三个日常的具体例子作起点：空白的大问题让人答不上来，例子让人想起自己的那一件。
2. **先读简历和文件，从它们显示的转折问起。** 「简历上从化学转去做数据，那一年发生了什么？」：从本人已经给的东西出发，本人不必从头讲。
3. **生涯建构的五个问题，一轮一两个。** 成长中敬佩谁（谁都可以，包括父母）、敬佩什么；反复回去看的杂志、节目、网站或账号，为什么；最喜欢的书或电影里的故事讲的是什么；信奉的一句话；最早能讲成一个小场景的记忆。每一个都照出本人在意的东西，敬佩的人常常就是想成为的样子。
4. **人生故事的三个关键场景。** 一个高峰、一个低谷、一个改变方向的转折点：何时、何地、谁、说了什么、当时感受、事后怎么解释；再问会怎样讲下一章。事后的解释比事件本身更能说明一个人。
5. **在故事里看三件事。** D8：难的时候自己扛还是有人帮，坏事后来有没有变成好事；D2：高峰和低谷里的内容是超越标准、影响别人还是关系；D0：当时的处境和约束。
6. **低谷可能碰到艰难时期。** 本人谈到伤害自己或不想活的念头，按「安全」一节处理，不追问经过。
