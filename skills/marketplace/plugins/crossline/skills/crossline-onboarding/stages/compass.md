# 本阶段：compass 指南针

本人的工作观和人生观，以及两者是否一致。这一部分看 D4、D5、D3。

右栏：画像图（价值）。

1. **问工作观。** 工作为了什么、什么样的工作值得做、钱和意义各占多少、好工作和坏工作的分界在哪；用本人做过的一份工作或一个项目作例子回答。
2. **问人生观。** 什么让生活值得、对别人和社会的责任、什么是好的一生；同样要一个具体的人或场景作例子。
3. **看一致。** 把工作观和人生观并排放：一致的地方说一次，冲突的地方问本人平时怎么取舍，最近一次是怎么选的。
4. **价值排序看行为。** 嘴上排第一的价值，时间和钱是不是流向那里；不一致时，问一个能区分两种解释的问题。
5. **问敬佩谁、嫉妒谁。** 成长中敬佩的人和最近嫉妒的人，各敬佩、嫉妒的是哪一点：那常常就是想成为的样子。
