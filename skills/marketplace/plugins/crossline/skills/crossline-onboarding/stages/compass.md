# 本阶段：compass 指南针

为什么工作、什么让人生值得过。这一阶段看 D4、D5、D3。

1. **问为什么工作，不问哪份工作。** 为了钱、为了别人、为了世界；什么让人生值得过；两者在哪里互相拉扯（D4、D3）。具体的工作会变，背后的理由不太变。
2. **用两难取舍问价值排序，不逐项打分。** 人人都会给每个价值打高分，只有取舍排得出先后：「多一倍收入但离家远，还是收入不变留在原地？」
3. **对每条主线问「为什么做」，追问到第三层。** 听它属于「不做会内疚、怕被看不起」「我认同它的价值」还是「做着就开心」：动机从哪来，决定推进它时累不累、能坚持多久。
4. **问希望成为的自己和害怕成为的自己（D5）。** 害怕的那个比希望的更具体时，动力以回避为主；这会影响什么样的目标对本人有用。
5. **把说的价值和时间、钱的去向对照。** 嘴上排第一的价值，时间和钱却流向别处：这是本人自己不容易看到的地方（D4），用问题核对，不直接下结论。
